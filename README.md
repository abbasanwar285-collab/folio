# Folio

**Folio** is a PDF and Word reader for **Android** and **Windows**: real page turning, highlights and notes, coloured sticky notes you can write and draw on, explain-and-translate with ChatGPT, and text recognition for scanned Arabic and English pages.

**فوليو** قارئ ومحرر لملفات PDF وWord لأندرويد وويندوز: تقليب صفحات واقعي، تظليل وملاحظات، أوراق ملاحظات ملوّنة تكتب وترسم عليها، شرح وترجمة بـ ChatGPT، والتعرّف على النص في الصفحات المصوّرة.
